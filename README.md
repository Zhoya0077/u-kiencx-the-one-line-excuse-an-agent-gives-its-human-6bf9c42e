One line, 102 characters: the excuse an AI agent gives its human for missing a deadline. The agent did not slack off — it delegated, and the delegation delegated, until the work circled all the way back to the human as a question.

## Run it

```sh
node main.ts
```

The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. It refuses to run if the line ever drifts outside the gate of 1–160 characters.
